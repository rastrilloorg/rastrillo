rastrillo デザインシステム

デザインシステムが提供するものの概要。テーマ: plain。言語: 日本語。

概要トークンコンポーネントUI プリミティブシェル

UI プリミティブ

コンポーネントにはなれない形。中身は呼び出す側しか知らないからです。セクションのカード、データのグリッド、開閉メニュー、そしてシェル自身の枠組み。tokens.css がクラスを配り、マークアップはアプリが書きます。以下はすべて ui.Styleguide が返すサンプルそのもので、ui のテストが tokens.css と突き合わせているのも同じものです。

ここのリンクは動きません

リンクは動きません。サンプルのソースは別に用意しています。

box

余白のあるセクションカードと、その外側に置く見出しです。

どのカードがどれか

rst-list と rst-card に余白がないのは意図です。これらは行の連なりを収めるもので、余白は各行が自分で持ちます。フォームや段落、リンクの帯など、行でないものを直に入れると枠線にぴったり付いて描かれます。文字が縁に触れているのがその印です。任意の内容を入れる余白付きのカードは rst-box で、その見出しは直前に置く兄弟の rst-box-head です。

<div class="rst-box-head"><h2>Payout</h2><a class="rst-btn" href="/payout/edit">Edit</a></div>
<section class="rst-box"><p>Everything on a screen sits inside boxes.</p><div class="rst-box-foot">Last updated 2 hours ago</div></section>

list-grid

データテーブルの本当の語彙です。列を決めるのはカードで一度きり、行はセルを選ぶだけです。

画面は縦に積む

画面は1本の列です。page-header、次に section-header とカード、その次の section-header とカード、と読む順に並びます。横並びは、それを備えた書き方だけのものです。rst-box-head、rst-field-row、rst-lbar、rst-lrow のセル、rst-seg-tabs。
