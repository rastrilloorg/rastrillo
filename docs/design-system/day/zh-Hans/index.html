rastrillo 设计系统

设计系统所提供内容的总览。主题：day。语言：简体中文。

概览设计变量组件界面基元页面外壳

概览

Rastrillo 设计系统想成为任何应用的起步框架：一致、精致、无障碍的界面，不依赖或极少依赖 JavaScript，支持多种语言，用干净、现代的 HTML 和 CSS 写成。它的设计让人用起来愉快，有没有 LLM 协助都一样，而且很容易改造重组。

演示应用

一个完全用这套系统搭出来的可用应用：一块仪表板、一份列表和一条打开的记录，每一个视图都有自己的地址，而且上面没有任何东西需要 JavaScript 才能用。

预览

打开演示应用 (在新标签页中打开).

接下来去哪里

  • 设计变量构成整个系统的每一个自定义属性：主题的颜色与字体，以及字号、间距和圆角的比例。
  • 组件框架的模板 partial，每一个都以它自带的每种状态渲染出来，旁边附上标记。
  • 界面基元组件无法成为的那些形状，因为它们包住的主体只有调用方知道：卡片、数据网格、菜单，以及外壳自身的框架。
  • 页面外壳rastrillo new 能生成的三种页面框架，每一种都可以作为整页以全宽打开。
