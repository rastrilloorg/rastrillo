Step 5 · Build a blog

Give posts a table

A post needs somewhere to live. Add a model and a migration that creates its table. Migrations run once, in order, when the app boots.

Open internal/blog/models.go and add the Post type shown on the right. Then add migration 0002 in migrations.go.

The dev server notices the save, rebuilds, and applies the migration as it restarts.

Check it workedThe dev server's log says applied 0002_posts.
