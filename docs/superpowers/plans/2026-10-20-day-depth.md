# Day depth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `day` its own personality (monochrome neutrals, cobalt, 6px/4px corners, natural depth lit from above, a press that sinks and slowly lifts) and a deletable `light.js` that moves the light with the pointer, while `plain`, `signal` and every app's own theme render exactly as they do today.

**Architecture:** Depth is a theme axis. `ui/themes/*.css` declare every new token (every theme, every token: C1); `ui/tokens.css` composes them into each component's faces, shadows and states, reading each one through a fallback that is today's value, so an old theme renders as today, and `plain` and `signal` declare today's values, so they render as today too. `tokens.css` registers `--rst-press` so a release can fade. `ui/light.js` is a new vendored enhancement that only writes custom properties (`--rst-light-x/-y` on `:root`, `--rst-mx/-my/-px/-py` on buttons, `--rst-card-x/-y/-lit` on cards); without it every property holds the default that is the static design. Delivery goes through `ui.VendoredAssets`, the five shell layouts, the scaffold, `rastrillo doctor` and the gallery. A pixel-level state matrix (Task 3) holds the two promises above from the first commit that could break them to the last.

**Tech Stack:** Go 1.26 (root module `amadan.net/rastrillo/rastrillo`), hand-written CSS (`light-dark()`, `color-mix()`, `@property`, `:has()`, `:not()` with complex selectors), dependency-free CSP-clean JavaScript (IIFE, two-space indent), chromedp drives in Chromium through `harness` (`//go:build browser`; `cdproto` `css`, `dom`, `emulation`, `input`, `tracing`), axe-core in `internal/designsystem/a11y_test.go`.

**Spec:** `docs/superpowers/specs/2026-10-20-day-depth-design.md`, including "Engineering constraints" C1 to C17 and "Amendments from planning" A1 to A18, which bind this plan. The mockups beside it (`2026-10-20-day-depth/*.css`, `light.js`) and the later `alive.css`/`alive.js` the amendments cite are the visual reference; none of their `!important` survives.

```go
// schemeNumberBlocks returns the bodies of a theme's two dark-number
// blocks, or nil when it has none, and fails the test for every problem
// schemeNumberProblems reports.
func schemeNumberBlocks(t *testing.T, name, css string) []string {
	t.Helper()
	blocks, problems := schemeNumberProblems(name, css)
	for _, p := range problems {
		t.Error(p)
	}
	return blocks
}

// schemeNumberProblems reads a theme file against the shape A4 allows:
// one `:root {` block; the two toggle rules
// `:root[data-theme="light"] { color-scheme: light; }` and
// `:root[data-theme="dark"] { color-scheme: dark; }`; and, together or
// not at all, `:root[data-theme="dark"] { numbers }` and
// `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { numbers } }`.
// Every declaration in a number block must be a --rst-* name with a
// bare number (an optional px, em or rem unit), nothing else may be in
// the block, the two blocks must carry identical declarations, and
// every name restated must be declared in :root as a number too. Both
// blocks, because a reader who chose Dark has data-theme and a reader on
// System on a dark OS has only the media query; one block alone hands
// the other reader the light numbers. Nothing beyond those five pieces
// may be in the file: anything else is the second palette block
// light-dark() was adopted to make impossible.
func schemeNumberProblems(name, css string) (blocks []string, problems []string) {
	where := "themes/" + name + ".css"
	bad := func(format string, args ...any) { problems = append(problems, where+": "+fmt.Sprintf(format, args...)) }
	stripped := regexp.MustCompile(`(?s)/\*.*?\*/`).ReplaceAllString(css, "")
	const (
		toggleLight = `:root[data-theme="light"] { color-scheme: light; }`
		toggleDark  = `:root[data-theme="dark"] { color-scheme: dark; }`
	)
	if strings.Count(stripped, toggleLight) != 1 || strings.Count(stripped, toggleDark) != 1 {
		bad("does not carry the two toggle rules exactly once")
	}
	rest := strings.Replace(strings.Replace(stripped, toggleLight, "", 1), toggleDark, "", 1)
	rootRe := regexp.MustCompile(`(?s):root \{(.*?)\n\}`)
	rootM := rootRe.FindStringSubmatch(rest)
	if rootM == nil {
		bad("has no :root block")
		return nil, problems
	}
	root := rootM[1]
	rest = strings.Replace(rest, rootM[0], "", 1)
	attr := regexp.MustCompile(`:root\[data-theme="dark"\] \{([^{}]*)\}`).FindAllStringSubmatch(rest, -1)
	media := regexp.MustCompile(`@media \(prefers-color-scheme: dark\) \{\s*:root:not\(\[data-theme="light"\]\) \{([^{}]*)\}\s*\}`).FindAllStringSubmatch(rest, -1)
	for _, m := range attr {
		rest = strings.Replace(rest, m[0], "", 1)
	}
	for _, m := range media {
		rest = strings.Replace(rest, m[0], "", 1)
	}
	if strings.TrimSpace(rest) != "" {
		bad("carries rules beyond :root, the toggles and the two dark-number blocks:\n%s", strings.TrimSpace(rest))
	}
	if len(attr) == 0 && len(media) == 0 {
		return nil, problems
	}
	if len(attr) != 1 || len(media) != 1 {
		bad("has %d attribute and %d media dark-number blocks, want one of each or none", len(attr), len(media))
		return nil, problems
	}
	decl := regexp.MustCompile(`^(--rst-[a-z0-9-]+)\s*:\s*(.+)$`)
	num := regexp.MustCompile(`^-?[0-9]*\.?[0-9]+(px|em|rem)?$`)
	inRoot := parseTokens(root)
	read := func(body string) map[string]string {
		out := map[string]string{}
		// Every declaration is consumed by the numeric grammar, or the
		// block is rejected: a stray `color: red;` must not pass because
		// the reader only looked for --rst- names.
		for _, d := range strings.Split(body, ";") {
			d = strings.TrimSpace(d)
			if d == "" {
				continue
			}
			m := decl.FindStringSubmatch(d)
			if m == nil {
				bad("has %q in a scheme block; only --rst-* numbers may be restated per scheme", d)
				continue
			}
			v := strings.TrimSpace(m[2])
			if !num.MatchString(v) {
				bad("restates %s as %q in a scheme block; only numbers may be restated per scheme", m[1], v)
			}
			if rv, ok := inRoot[m[1]]; !ok {
				bad("restates %s for dark but never declares it in :root", m[1])
			} else if !num.MatchString(rv) {
				bad("declares %s as %q in :root; a number restated per scheme must be a number there too", m[1], rv)
			}
			out[m[1]] = v
		}
		return out
	}
	a, m := read(attr[0][1]), read(media[0][1])
	if !reflect.DeepEqual(a, m) {
		bad("two dark-number blocks differ: attribute %v, media %v", a, m)
	}
	return []string{attr[0][1], media[0][1]}, problems
}

// TestSchemeNumberGateRejectsWhatItMustReject feeds the gate the shapes
// it exists to refuse, since a gate that only ever sees the shipped
// themes is not known to refuse anything.
func TestSchemeNumberGateRejectsWhatItMustReject(t *testing.T) {
	const good = ":root {\n  --rst-bg: light-dark(#fff, #000);\n  --rst-press-wash: 0.08;\n}\n:root[data-theme=\"light\"] { color-scheme: light; }\n:root[data-theme=\"dark\"] { color-scheme: dark; }\n:root[data-theme=\"dark\"] { --rst-press-wash: 0.18; }\n@media (prefers-color-scheme: dark) { :root:not([data-theme=\"light\"]) { --rst-press-wash: 0.18; } }\n"
	if blocks, problems := schemeNumberProblems("good", good); len(problems) != 0 || len(blocks) != 2 {
		t.Fatalf("the well-formed theme was refused: %v (%d blocks)", problems, len(blocks))
	}
	for name, css := range map[string]string{
		"a colour in a block":       strings.ReplaceAll(good, "--rst-press-wash: 0.18;", "--rst-press-wash: 0.18; color: red;"),
```

#### The C11 state tables

Every cell is the whole value the rule sets; a blank cell inherits the row above. "layers" is `background-image`, always four layers in this order: the sheen, the press spot, the press wash, the face. The spot is `radial-gradient(70px circle at var(--rst-px) var(--rst-py), rgb(0 0 0 / calc(var(--rst-press) * var(--rst-btn-spot))), transparent 75%)`; the wash is `linear-gradient(rgb(0 0 0 / calc(var(--rst-press) * var(--rst-btn-wash))) 0 0)`; both are at alpha 0 at rest because `--rst-press` is 0. "outer" is `inset var(--rst-hl-x) 1px 0 HL, var(--rst-shadow-x) var(--rst-shadow-y) 1px var(--rst-depth-contact, transparent), calc(var(--rst-shadow-x) * 2) calc(var(--rst-shadow-y) * 1.5) 3px var(--rst-depth-ambient, transparent)` with HL per variant; "sunk" is `inset 0 2px 4px var(--rst-depth-contact, transparent), inset 0 1px 1px var(--rst-depth-contact, transparent), inset 0 1px 2px var(--rst-depth-contact, transparent)`. Hover rows apply inside `@media (hover: hover)` to every button, disabled and busy ones included, because that is what every theme does today and a disabled button that stopped answering the pointer would be a visible change under an old theme (the matrix pins `#b-off` hovered); press rows apply to `:active:not(:disabled):not([aria-busy="true"])` and come last in the section (a disabled button is never `:active` in a browser, so the exclusion changes no pixel today). Every token is read with its fallback, which is today's value, so an old theme gets today's table.

```css
	}
```

```go
		rest := read(id)
		forceState(t, ctx, id, "hover")

		forceState(t, ctx, id, "hover", "active")
		press := read(id)
		forceState(t, ctx, id)
		if rest == hover {
			t.Errorf("%s: hover is the rest face %+v", id, rest)
		}
		if hover == press {
			t.Errorf("%s: press is the hover face %+v; a pressed face replaces the hovered face (C11)", id, hover)
		}
		if id == "#b-primary" || id == "#b-danger" || id == "#b-link" {
			if hover.bg == rest.bg {
				t.Errorf("%s: hover keeps the rest fill %s; every state reads its own token (C3)", id, rest.bg)
			}
			if isGrey(hover.bg) {
				t.Errorf("%s: hovered fill %s is grey; a filled button's hover keeps its fill", id, hover.bg)
			}
			if !strings.Contains(hover.img, "radial-gradient(120px") {
				t.Errorf("%s: hover has no 120px sheen: %q", id, hover.img)
			}
		}
		if id == "#b-plain" && !strings.Contains(hover.img, "radial-gradient(90px") {
			t.Errorf("#b-plain: hover has no 90px sheen: %q", hover.img)
		}
		if strings.Contains(press.img, "radial-gradient(90px") || strings.Contains(press.img, "radial-gradient(120px") {
			t.Errorf("%s: the sheen is still on while pressed: %q", id, press.img)
		}
	}
	for _, pair := range [][2]string{{"#b-plain", "#b-plain-c"}, {"#b-primary", "#b-primary-c"}} {
		for _, states := range [][]string{{}, {"hover"}, {"hover", "active"}} {
			forceState(t, ctx, pair[0], states...)
			forceState(t, ctx, pair[1], states...)
			if a, b := read(pair[0]), read(pair[1]); a != b {
				t.Errorf("%s and %s differ in state %v: %+v vs %+v; both spellings are one rule (C12)", pair[0], pair[1], states, a, b)
			}
			forceState(t, ctx, pair[0])
			forceState(t, ctx, pair[1])
		}
	}
	// A disabled or busy button hovers like any other (today's
	// behaviour in every theme) and never presses: the press rule
	// excludes it, and a browser never makes a disabled button :active.
	// The sheen is not compared: it is keyed on :not(:active), which a
	// forced state can set on a disabled button where a pointer cannot.
	for _, id := range []string{"#b-off", "#b-busy"} {
		forceState(t, ctx, id, "hover")
		hover := read(id)
		forceState(t, ctx, id, "hover", "active")

		forceState(t, ctx, id)
		hover.img, got.img = "", ""
		if got != hover {
			t.Errorf("%s pressed while hovered: %+v -> %+v; a disabled or busy button has no press", id, hover, got)
		}
	}

// cssColour spells a theme token the way Chromium serialises a computed
// colour: a hex as rgb(r, g, b), an rgba() with its alpha as the
// shortest decimal, transparent as rgba(0, 0, 0, 0). channelsOf and
// alphaOf are contrast_face_test.go's.
func cssColour(t *testing.T, v string) string {
	t.Helper()
	v = strings.TrimSpace(v)
	if v == "transparent" {
		return "rgba(0, 0, 0, 0)"
	}
	c, a := channelsOf(t, v), alphaOf(t, v)
	if a >= 1 {
		return fmt.Sprintf("rgb(%d, %d, %d)", int(c[0]), int(c[1]), int(c[2]))
	}
	return fmt.Sprintf("rgba(%d, %d, %d, %s)", int(c[0]), int(c[1]), int(c[2]), strconv.FormatFloat(a, 'f', -1, 64))
}
```

```go
func faceShadeShape(t *testing.T) {
	t.Helper()
	if !regexp.MustCompile(`--rst-btn-face: linear-gradient\(rgb\(255 255 255 / var\(--rst-depth-face, 0\)\), rgb\(0 0 0 / var\(--rst-depth-face, 0\)\)\)`).Match(TokensCSS()) {

	}

func alphaOf(t *testing.T, v string) float64 {
	t.Helper()
	v = strings.TrimSpace(v)
	if v == "transparent" {
		return 0
	}
	if strings.HasPrefix(v, "#") {
		return 1
	}
	m := regexp.MustCompile(`rgba?\([^)]*?[,/]\s*([0-9.]+)\s*\)$`).FindStringSubmatch(v)
	if m == nil {
		t.Fatalf("cannot read an alpha from %q", v)
	}
	a, err := strconv.ParseFloat(m[1], 64)
	if err != nil {
		t.Fatal(err)
	}
	return a
}

func channelsOf(t *testing.T, v string) [3]float64 {
	t.Helper()
	v = strings.TrimSpace(v)
	if v == "transparent" {
		return [3]float64{}
	}
	if strings.HasPrefix(v, "#") {
		r, g, b, err := parseHex(v)
		if err != nil {
			t.Fatal(err)
		}
		return [3]float64{float64(r), float64(g), float64(b)}
	}
	m := regexp.MustCompile(`rgba?\(\s*([0-9]+)[,\s]+([0-9]+)[,\s]+([0-9]+)`).FindStringSubmatch(v)
	if m == nil {
		t.Fatalf("cannot read channels from %q", v)
	}
	var out [3]float64
	for i := range out {
		n, _ := strconv.Atoi(m[i+1])
		out[i] = float64(n)
	}
	return out
}

// over composites fg at alpha a over an opaque bg in sRGB, which is what
// a gradient layer does, and returns hex for ContrastRatio.
func over(t *testing.T, bg, fg string, a float64) string {
	t.Helper()
	B, F := channelsOf(t, bg), channelsOf(t, fg)
	var out [3]uint8
	for i := range out {
		out[i] = uint8(math.Round(F[i]*a + B[i]*(1-a)))
	}
	return hexOf(out)
}

func hexChannels(t *testing.T, v string) string {
	t.Helper()
	c := channelsOf(t, v)
	return fmt.Sprintf("#%02x%02x%02x", int(c[0]), int(c[1]), int(c[2]))
}

// pressNumber reads a number token, from the dark scheme blocks for
// dark, and fails on anything that is not a number: a value that parsed
// as 0 would make every press look safe. (Not "number": the package
// imports golang.org/x/text/number.)
func pressNumber(t *testing.T, theme, scheme, name string) float64 {
	t.Helper()
	v := themeTokens(t, theme)["light"][name]
	if scheme == "dark" {
		css, _ := ThemeCSS(theme)
		for _, block := range schemeNumberBlocks(t, theme, string(css)) {
			if m := regexp.MustCompile(regexp.QuoteMeta(name) + `\s*:\s*([^;]+);`).FindStringSubmatch(block); m != nil {
				v = strings.TrimSpace(m[1])
			}
		}
	}
	f, err := strconv.ParseFloat(v, 64)
	if err != nil {
		t.Fatalf("%s/%s %s = %q is not a number", theme, scheme, name, v)
	}
	return f
}
```

```go
// samePixels reports whether two PNGs agree within the tolerance above.
func samePixels(t *testing.T, a, b []byte) (bool, string) {
	t.Helper()
	ia, err := png.Decode(bytes.NewReader(a))
	if err != nil {
		t.Fatal(err)
	}
	ib, err := png.Decode(bytes.NewReader(b))
	if err != nil {
		t.Fatal(err)
	}
	if ia.Bounds() != ib.Bounds() {
		return false, fmt.Sprintf("sizes differ: %v vs %v", ia.Bounds(), ib.Bounds())
	}
	bad, total := 0, 0
	for y := ia.Bounds().Min.Y; y < ia.Bounds().Max.Y; y++ {
		for x := ia.Bounds().Min.X; x < ia.Bounds().Max.X; x++ {
			ra, ga, ba, _ := ia.At(x, y).RGBA()
			rb, gb, bb, _ := ib.At(x, y).RGBA()
			total++
			d := func(p, q uint32) int {
				v := int(p>>8) - int(q>>8)
				if v < 0 {
					v = -v
				}
				return v
			}
			if m := max(d(ra, rb), d(ga, gb), d(ba, bb)); m > 8 {
				return false, fmt.Sprintf("pixel %d,%d differs by %d", x, y, m)
			} else if m > 0 {
				bad++
			}
		}
	}
	if float64(bad) > float64(total)*0.01 {
		return false, fmt.Sprintf("%d of %d pixels differ", bad, total)
	}
	return true, ""
}

// matrixShots photographs the whole page once per state set under one
// stylesheet pair and scheme, with the state pinned on every target that
// lists it at the same time. One full-page shot per state set rather
// than one shot per element: the per-element version took over ten
// minutes for the five pairs, and the pixels are the same pixels.
func matrixShots(t *testing.T, ctx context.Context, origin, dir, scheme string) map[string][]byte {
	t.Helper()
	mustRun(t, ctx, chromedp.EmulateViewport(1280, 1600), chromedp.Navigate(origin+dir), chromedp.WaitVisible("#field", chromedp.ByQuery),
		chromedp.Evaluate(`document.documentElement.setAttribute("data-theme", "`+scheme+`"), document.getElementById("dd").open = true, true`, nil))
	still(t, ctx)
	out := map[string][]byte{}
	for _, states := range matrixStates {
		var pinned []string
		for _, target := range matrixTargets {
			for _, s := range target.states {
				if strings.Join(s, "+") == strings.Join(states, "+") {
					force := target.force
					if force == "" {
						force = target.selector
					}
					forceState(t, ctx, force, states...)
					pinned = append(pinned, force)
				}
			}
		}
		var buf []byte
		mustRun(t, ctx, chromedp.FullScreenshot(&buf, 100))
		out[scheme+" "+strings.Join(states, "+")] = buf
		for _, force := range pinned {
			forceState(t, ctx, force)
		}
	}
	return out
}
```

```go
// switchSheen reads the on track's sheen position as the browser
// resolved it: the x offset of the 40px radial gradient relative to the
// track's centre, in px, signed as the screen has it. The gradient is
// written as calc(50% + dir * (x - 7.5px)); Chromium serialises the
// resolved calc as "calc(50% + Npx)" or "calc(50% - Npx)".
func switchSheen(t *testing.T, ctx context.Context, sel string) (present bool, offset float64) {
	t.Helper()
	var img string
	mustRun(t, ctx, chromedp.Evaluate(`getComputedStyle(document.querySelector(`+jsStr(sel)+` + " [rst-switch-track]")).backgroundImage`, &img))
	m := regexp.MustCompile(`radial-gradient\(40px at calc\(50% ([+-]) ([0-9.]+)px\)`).FindStringSubmatch(img)
	if m == nil {
		return false, 0
	}
	v, _ := strconv.ParseFloat(m[2], 64)
	if m[1] == "-" {
		v = -v
	}
	return true, v
}
```

```go
// noShadow: none, or a shadow list whose every colour is fully
// transparent, which is what a token set flat computes to; an element
// with such a list paints nothing.
func noShadow(v string) bool {
	if v == "none" {
		return true
	}
	for _, c := range regexp.MustCompile(`rgba?\([^)]*\)|color\([^)]*\)`).FindAllString(v, -1) {
		if !strings.HasSuffix(c, ", 0)") && !strings.HasSuffix(c, "/ 0)") {
			return false
		}
	}
	return true
}

// noMove: none, or a translate whose every length is 0px (a 0px drop
// computes to "0px", not to none).
func noMove(v string) bool {
	if v == "none" {
		return true
	}
	for _, f := range strings.Fields(v) {
		if f != "0px" {
```

```go
// lightFrameBudgetMS is C9's budget: style recalculation, layout,
// pre-paint and paint per frame while the pointer moves over a 500-row
// list, summed from the browser's own trace events. The spec's ceiling
// is 4ms on the CI runner; the measured figures are recorded below.
const lightFrameBudgetMS = 4.0

// traceCategories are the ones that carry the rendering events this
// drive sums (measured in this Chromium): UpdateLayoutTree is in
// "blink,devtools.timeline", Layout, PrePaint and Paint in
// "devtools.timeline". "disabled-by-default-devtools.timeline" alone,
// which a first draft enabled, carries none of them and would have
// summed to a passing zero.
var traceCategories = []string{"devtools.timeline", "blink", "disabled-by-default-devtools.timeline"}

// traceTotals sums the duration of the named events from a trace:
// complete events ("X") by their dur, and begin/end pairs ("B"/"E") by
// their timestamps, matched by name in order. It also counts each
// name, so a trace that carried none of them fails rather than
// measuring nothing.
func traceTotals(events []json.RawMessage, names ...string) (total float64, counts map[string]int) {
	want := map[string]bool{}
	for _, n := range names {
		want[n] = true
	}
	counts = map[string]int{}
	open := map[string][]float64{}
	for _, raw := range events {
		var e struct {
			Name string  `json:"name"`
			Ph   string  `json:"ph"`
			Dur  float64 `json:"dur"`
			Ts   float64 `json:"ts"`
		}
		if json.Unmarshal(raw, &e) != nil || !want[e.Name] {
			continue
		}
		switch e.Ph {
		case "X":
			total += e.Dur
			counts[e.Name]++
		case "B":
			open[e.Name] = append(open[e.Name], e.Ts)
		case "E":
			if n := len(open[e.Name]); n > 0 {
				total += e.Ts - open[e.Name][n-1]
				open[e.Name] = open[e.Name][:n-1]
				counts[e.Name]++
			}
		}
	}
	return total, counts
}

// TestTheLightStaysWithinItsFrameBudget (C9): two seconds of pointer
// movement over 500 rows, a move every 16ms. The trace's
// UpdateLayoutTree (style), Layout, PrePaint and Paint durations are
// summed and divided by the frames the page counted; the trace must
// carry style and paint events or the figure proves nothing. Also:
// <html>'s style is written at most twice a frame (two properties, one
// update), and no long task occurs.
//
// Measured (fill in on the first run, Step 4): N.NN, N.NN, N.NN ms a
// frame on docs-t1 under make browser.
func TestTheLightStaysWithinItsFrameBudget(t *testing.T) {
	var rows strings.Builder
	rows.WriteString(`<div rst-page><div rst-card id="big" style="--rst-cols: 1fr auto">`)
	for i := 0; i < 500; i++ {
		fmt.Fprintf(&rows, `<div rst-lrow><a class="rst-nm" href="#r%d">Row %d</a><button rst-btn="sm">Open</button></div>`, i, i)
	}
	rows.WriteString(`</div></div>`)
	doc := strings.Replace(sizingDoc("budget", rows.String()), `<script defer src="/busy.js"></script>`, `<script defer src="/busy.js"></script><script defer src="/light.js"></script>`, 1)
	rig := sizingRig(t, false, map[string]string{"/": doc})
	ctx, cancel := context.WithTimeout(rig.Context(), 90*time.Second)
	defer cancel()
	mustRun(t, ctx, chromedp.EmulateViewport(1280, 800), chromedp.Navigate(rig.Origin+"/"), chromedp.WaitVisible("#big", chromedp.ByQuery),
		chromedp.Evaluate(`window.__frames = 0; window.__long = 0; (function f() { window.__frames++; requestAnimationFrame(f); })(); new PerformanceObserver(l => window.__long += l.getEntries().length).observe({type: "longtask"}); window.__rootWrites = 0; new MutationObserver(m => window.__rootWrites += m.length).observe(document.documentElement, {attributes: true, attributeFilter: ["style"]}); true`, nil))
	var events []json.RawMessage
	done := make(chan struct{})
	chromedp.ListenTarget(ctx, func(ev interface{}) {
		switch e := ev.(type) {
		case *tracing.EventDataCollected:
			for _, v := range e.Value {
				events = append(events, json.RawMessage(v))
			}
		case *tracing.EventTracingComplete:
			close(done)
		}
	})
	var frames0 int
	mustRun(t, ctx, chromedp.Evaluate(`window.__frames`, &frames0),
		chromedp.ActionFunc(func(c context.Context) error {
			return tracing.Start().WithTransferMode(tracing.TransferModeReportEvents).WithTraceConfig(&tracing.TraceConfig{IncludedCategories: traceCategories}).Do(c)
		}))
	start := time.Now()
	for i := 0; time.Since(start) < 2*time.Second; i++ {
		mustRun(t, ctx, chromedp.MouseEvent(input.MouseMoved, 200+float64(i%60)*15, 100+float64(i%40)*16), chromedp.Sleep(16*time.Millisecond))
	}
	var frames1, long, writes int
	mustRun(t, ctx, chromedp.Evaluate(`window.__frames`, &frames1), chromedp.Evaluate(`window.__long`, &long), chromedp.Evaluate(`window.__rootWrites`, &writes),
		chromedp.ActionFunc(func(c context.Context) error { return tracing.End().Do(c) }))
	select {
	case <-done:
	case <-time.After(20 * time.Second):
		t.Fatal("the trace never completed")
	}
	frames := frames1 - frames0
	if frames < 60 {
		t.Fatalf("only %d frames in 2s; the page is not animating, the figure would prove nothing", frames)
	}
	total, counts := traceTotals(events, "UpdateLayoutTree", "Layout", "PrePaint", "Paint")
```

```js
(function () {
  "use strict";
  var root = document.documentElement;
  var reduce = matchMedia("(prefers-reduced-motion: reduce)");
  var forced = matchMedia("(forced-colors: active)");

  // FOLLOW is C9's fallback: false drops the pointer-following root
  // light for the hour-only light and keeps the per-element sheen.
  var FOLLOW = true;
  var BTN = "[rst-btn],.rst-btn";
  var CARD = "[rst-box],.rst-box,[rst-card],.rst-card,[rst-stats],.rst-stats,[rst-list],.rst-list";
  // Time constants in ms: the light settles in about a third of a
  // second, a card's spot follows at a walk, its brightness over about
  // a second. Elapsed time, not a per-frame step, so 120 Hz is no faster.
  var LIGHT_T = 125, CARD_T = 320, LIT_T = 400;

  var on = false, tx = 0, ty = -1, lx = 0, ly = -1, wx = 0, wy = -1;
  var raf = 0, last = 0, pending = null, pointer = false, hold = false, force = false;
  var cards = new WeakMap(), live = new Set(), timers = new Set(), clock = 0;

  function sun() {
    var d = new Date(), h = d.getHours() + d.getMinutes() / 60;
    var t = Math.max(-1, Math.min(1, (h - 12) / 6));
    return [t * 0.8, -1 + Math.abs(t) * 0.35];
  }
  function target() {
    if (hold || (pointer && FOLLOW)) return;
    var s = sun();
    tx = s[0];
    ty = s[1];
  }
  // Every path that wants a frame comes through here, so a timer or a
  // move that fires after stop() or while the page is hidden schedules
  // nothing.
  function go() {
    if (!on || document.hidden) return;
    if (!raf) raf = requestAnimationFrame(step);
  }
  function ease(v, to, dt, T) {
    return v + (to - v) * (1 - Math.exp(-dt / T));
  }
  function light(el, x, y) {
    var o = cards.get(el);
    if (!o) { o = { x: x, y: y, l: 0 }; cards.set(el, o); }
    o.tx = x; o.ty = y; o.tl = 1;
    live.add(el);
  }
  function dim(el) {
    var o = cards.get(el);
    if (o) { o.tl = 0; live.add(el); }
  }

  // One loop. Every read (the pending move's rectangles) happens before
  // any write, and it reschedules itself only while something is still
  // easing.
  function step(now) {
    raf = 0;
    var dt = last ? Math.min(100, now - last) : 16;
    last = now;
    var moving = false;
    if (pending) {
      var e = pending;
      pending = null;
      var b = e.target.closest && e.target.closest(BTN);
      var c = e.target.closest && e.target.closest(CARD);
      var br = b && b.getBoundingClientRect();
      var cr = c && c.getBoundingClientRect();
      if (b) {
        b.style.setProperty("--rst-mx", (e.clientX - br.left).toFixed(0) + "px");
        b.style.setProperty("--rst-my", (e.clientY - br.top).toFixed(0) + "px");
      }
      live.forEach(function (k) { if (k !== c) dim(k); });
      if (c) light(c, e.clientX - cr.left, e.clientY - cr.top);
    }
    if (!hold) {
      lx = ease(lx, tx, dt, LIGHT_T);
      ly = ease(ly, ty, dt, LIGHT_T);
    }
    if (force || Math.abs(lx - wx) > 0.01 || Math.abs(ly - wy) > 0.01) {
      force = false;
      wx = lx; wy = ly;
      root.style.setProperty("--rst-light-x", lx.toFixed(3));
      root.style.setProperty("--rst-light-y", ly.toFixed(3));
    }
    if (Math.abs(tx - lx) > 0.002 || Math.abs(ty - ly) > 0.002) moving = true;
    live.forEach(function (el) {
      if (!el.isConnected) { live.delete(el); return; }
      var o = cards.get(el);
      o.x = ease(o.x, o.tx, dt, CARD_T);
      o.y = ease(o.y, o.ty, dt, CARD_T);
      o.l = ease(o.l, o.tl, dt, LIT_T);
      var done = Math.abs(o.tx - o.x) < 0.5 && Math.abs(o.ty - o.y) < 0.5 && Math.abs(o.tl - o.l) < 0.004;
      if (done) { o.x = o.tx; o.y = o.ty; o.l = o.tl; }
      el.style.setProperty("--rst-card-x", o.x.toFixed(1) + "px");
      el.style.setProperty("--rst-card-y", o.y.toFixed(1) + "px");
      el.style.setProperty("--rst-card-lit", o.l.toFixed(3));
      if (!done) moving = true; else if (o.tl === 0) live.delete(el);
    });
    if (moving) go(); else last = 0;
  }

  function onMove(e) {
    if (e.pointerType !== "mouse") return;
    if (FOLLOW && !hold) {
      pointer = true;
      // The light sits at the pointer, a little above the page.
      tx = Math.max(-1, Math.min(1, (e.clientX / innerWidth - 0.5) * 2));
      ty = Math.max(-1, Math.min(1, (e.clientY / innerHeight - 0.5) * 2)) * 0.6 - 0.4;
    }
    pending = e;
    go();
  }
  // The press darkens most where it landed, for mouse and touch alike;
  // a touch leaves pointer mode, and a tapped card catches the light
  // briefly. Both rectangles are read before either element is written.
  function onDown(e) {
    var b = e.target.closest && e.target.closest(BTN);
    var c = e.pointerType !== "mouse" && e.target.closest && e.target.closest(CARD);
    var br = b && b.getBoundingClientRect();
    var cr = c && c.getBoundingClientRect();
    if (b) {
      b.style.setProperty("--rst-px", (e.clientX - br.left).toFixed(0) + "px");
      b.style.setProperty("--rst-py", (e.clientY - br.top).toFixed(0) + "px");
    }
    if (e.pointerType === "mouse") return;
    leavePointer();
    if (c) {
      light(c, e.clientX - cr.left, e.clientY - cr.top);
      var id = setTimeout(function () { timers.delete(id); dim(c); go(); }, 1400);
      timers.add(id);
      go();
    }
  }
  function leavePointer() {
    pointer = false;
    target();
    go();
  }
  function onLeave() {
    live.forEach(dim);
    leavePointer();
  }
  function onVisibility() {
    if (document.hidden) {
      if (raf) cancelAnimationFrame(raf);
      raf = 0; last = 0;
    } else {
      go();
    }
  }
  // The test hook (C14): sets the light at once and, with hold, keeps
  // it there against pointer moves until the next event without hold.
  function onHook(e) {
    var d = e.detail || {};
    hold = !!d.hold;
    if (typeof d.x === "number") { tx = lx = d.x; }
    if (typeof d.y === "number") { ty = ly = d.y; }
    force = true;
    go();
  }

  function start() {
    if (on) return;
    on = true;
    addEventListener("pointermove", onMove, { passive: true });
    addEventListener("pointerdown", onDown, { passive: true });
    addEventListener("keydown", leavePointer, { passive: true });
    document.addEventListener("pointerleave", onLeave);
    document.addEventListener("visibilitychange", onVisibility);
    document.addEventListener("rst:light", onHook);
    clock = setInterval(function () { target(); go(); }, 5 * 60 * 1000);
    target();
    go();
  }
  // Reduced motion is total, and forced colours drop every background
  // and shadow this file moves: under either, no listener, no frame, no
  // timer, and every property this file wrote goes back to its default.
  function stop() {
    if (!on) return;
    on = false;
    removeEventListener("pointermove", onMove);
    removeEventListener("pointerdown", onDown);
    removeEventListener("keydown", leavePointer);
    document.removeEventListener("pointerleave", onLeave);
    document.removeEventListener("visibilitychange", onVisibility);
    document.removeEventListener("rst:light", onHook);
    clearInterval(clock);
    timers.forEach(clearTimeout);
    timers.clear();
    if (raf) cancelAnimationFrame(raf);
    raf = 0; last = 0; pending = null; pointer = false; hold = false; force = false;
    lx = wx = tx = 0; ly = wy = ty = -1;
    live.clear();
    root.style.removeProperty("--rst-light-x");
    root.style.removeProperty("--rst-light-y");
    // Every element this file ever wrote on carries one of its
    // properties in its style attribute; no list of them is kept, so a
    // button or card replaced by a fragment is not retained here.
    var written = document.querySelectorAll('[style*="--rst-"]');
    for (var i = 0; i < written.length; i++) {
      ["--rst-mx", "--rst-my", "--rst-px", "--rst-py", "--rst-card-x", "--rst-card-y", "--rst-card-lit"].forEach(function (p) {
        written[i].style.removeProperty(p);
      });
    }
  }
  function settle() {
    if (reduce.matches || forced.matches) stop(); else start();
  }
  reduce.addEventListener("change", settle);
  forced.addEventListener("change", settle);
  settle();
})();
```

> Hover is quiet and press is clear. A plain button's hover is a light grey face and a darker border; a filled button's is a deeper fill; a ghost's is a surface tint. Rows, menu items and sidebar items lift: a 5% accent tint (9% in dark), a highlight along the top edge, no sheen. The current sidebar item is a selected thumb, and hovering another is a half-raised preview of it.
>
> A press is instant and slow to leave. The button drops 1px, loses its highlight and outer shadow for an inset one, switches its sheen off and darkens, most under the pointer; on release the darkness lifts over about 0.7s, the spot under the finger last. A row pressed, or its link tapped, takes a stronger tint and sinks. Under reduced motion nothing moves and nothing fades.
