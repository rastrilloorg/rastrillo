# Web docs (rastrillo.org/docs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a forty-two-page documentation site at `rastrillo.org/docs`, with the content living in this repo and gated by Go tests so it cannot drift from the code.

**Architecture:** Markdown under `docs/site/` plus `docs/site/nav.json` is the source of truth. A new `internal/docsite` package parses that corpus and five Go tests gate it (nav↔files, links↔anchors, CLI↔`cli.md`, exported symbols↔reference pages, ```go fences parse). The website repo vendors a copy via a sync script and renders it with Eleventy into static HTML plus raw `.md` twins, with zero client-side JavaScript.

**Tech Stack:** Go 1.22+ (`go/parser`, `go/ast`, `embed`), Eleventy 3 with `markdown-it-anchor`, Nunjucks, the CARLOS `ship`/`promote` deploy path.

**Spec:** `docs/superpowers/specs/2026-08-23-web-docs-design.md`

## Global Constraints

- **Two repos.** Content and gates in `rastrilloorg/rastrillo` (this worktree, branch `docs`). Rendering and deploy in `carlosframework/rastrillo-website` (branch `docs`).
- **Never `git merge` to main**, not even locally: every change is a PR, squash-merged.
- **Zero client-side JavaScript in the served site.** No search box. Eleventy and `node_modules` never ship; only `_site/` does.
- **Authorship marking.** Every prose file carries a visible `🤖` marker per the website's `CLAUDE.md`. Never hide a `🤖` in a comment. Never rewrite a block carrying a person marker.
- **Every technical claim traces to this repo** — its code, its tests, its examples. Check the claim against the source, never against previous copy.
- **No page documents something that does not exist**, including as "coming soon".
- **Every page stands alone.** No "as we saw above" across page boundaries; each page restates the minimum context it needs.
- **A limit is documented where the feature is**, in the body, in the same voice as the feature — not in a footnote.
- **Light and dark both work** via `prefers-color-scheme`.
- Slug set is fixed by the spec §2. Reference pages live under `docs/site/reference/`.

### Task 1: The docsite package and its five gates

The gates come first and the corpus is grown against them, so every later task is verified the moment it lands. Two seed pages exist only to prove the gates fire; Task 2 replaces them with real content.

**Files:**
- Create: `docs/site/nav.json`, `docs/site/getting-started.md`, `docs/site/reference/scope.md`
- Create: `internal/docsite/docsite.go`
- Test: `internal/docsite/nav_test.go`, `links_test.go`, `cli_test.go`, `symbols_test.go`, `fences_test.go`

**Interfaces:**
- Produces:
  - `type Page struct { Slug, Label, Blurb, Title, Path string; Body string; Headings []Heading; Links []Link; Fences []Fence }`
  - `type Heading struct { Level int; Text, Anchor string }`
  - `type Link struct { Target, Fragment string; Line int }`
  - `type Fence struct { Lang, Body string; Line int }`
  - `type Section struct { Title string; Pages []*Page }`
  - `type Site struct { Sections []Section; BySlug map[string]*Page }`
  - `func Load(root string) (*Site, error)` — root is the `docs/site` directory
  - `func Anchor(text string) string` — must match `markdown-it-anchor`'s default slugify
  - `func (s *Site) Pages() []*Page`
- Consumes: nothing.

- [ ] **Step 1: Write the failing nav test**

```go
package docsite

import "testing"

func TestNavAndFilesAgreeBothWays(t *testing.T) {
	site, err := Load("../../docs/site")
	if err != nil {
		t.Fatalf("load: %v", err)
	}
	seen := map[string]bool{}
	for _, p := range site.Pages() {
		if seen[p.Slug] {
			t.Errorf("%s appears in nav.json more than once", p.Slug)
		}
		seen[p.Slug] = true
		if p.Title == "" {
			t.Errorf("%s has no `# ` title", p.Slug)
		}
		if p.Blurb == "" {
			t.Errorf("%s has no blurb in nav.json", p.Slug)
		}
	}
	files, err := markdownFiles("../../docs/site")
	if err != nil {
		t.Fatalf("walk: %v", err)
	}
	for _, slug := range files {
		if !seen[slug] {
			t.Errorf("docs/site/%s.md exists but no nav.json entry reaches it", slug)
		}
	}
}
```

- [ ] **Step 5: Write the remaining four gates**

`links_test.go` — for every `Link` on every page, the target slug is in `BySlug`, and if `Fragment != ""`, that page has a `Heading` whose `Anchor` matches. Failure names the source page and line.

`fences_test.go` — for every `Fence` with `Lang == "go"`, parse with `go/parser`. Honour `<!-- docs:ignore Symbol reason -->` markers, failing any marker whose reason is empty.

The `glebarez`/`gorm.io/driver/sqlite` ban and *why* — double driver registration panics at init against `rastrillo/gormlite` over `modernc.org/sqlite`.

`migrations.md` — the fullest page. `rastrillo migration generate/check/new/status/baseline`; `Schema` vs `BootSchema` and `migrate.Merge` argument order as apply order; add a subsystem to `BootSchema`, never `Schema`; never edit a shipped migration; renames are hand-written; `--allow-destructive`. Then the two traps in full: the **ledger recovery order** (`baseline --through <id>` *first*, then apply by hand — stamping runs no DDL, and a bare `baseline` on an empty ledger adopts everything silently, skipping a pending data migration), and **the first deploy of a version with migrations must be schema-neutral** (generate `0001_init` from the models as already deployed, ship it alone).

`scoping.md` — the `owned(r)` seam; `scope.Owned`/`OwnedBy` with the `lower_snake` panic; scope the write not just the read; 404 never 403, including a malformed `{id}`; the transaction rule (a `d.G` statement inside a `Transaction` callback runs outside it, holding the one writer connection, so it hangs rather than errors); join tables scoped through both sides; create takes the owner from the session, never the form. Opens with the tenancy ruling: scoping separates users within one instance, never tenants — a CARLOS app serves one team, many teams means many hibernating instances.

`forms.md` — never bind a body onto a model; read each permitted field by name; `.Select(...)` as the allowlist; `form.Parse` with `form.Field`; the 422 re-render with `p.Errors()` and seeded values; `p.Echo()`; money as `int64` cents (`form.Money`, `p.Cents`, `ParseCents`, `FormatCentsPlain`, `FormatCents`); `flash.Set` then 303.
