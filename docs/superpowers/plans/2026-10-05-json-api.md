# JSON API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Rastrillo app gets a bearer-only JSON API at `/api/v1`, generated from its manifests, where each operation is one Go function shared by the page and the API, callers are personal tokens minted for a named agent, and every call records "Claude for Paul".

**Architecture:** Three new runtime packages (`op`, `api`, `apitoken`) plus root-package changes (`Actor`, `Access`, `Operation`, `Ctx.Authorize`). The generator gains a `gen/ops/<resource>` emitter, a `gen/api/<resource>.go` emitter, a contract file, a parity lint and a parity-test emitter; generated page actions are rewritten to call operations. The scaffold and the `notes`/`tickets` examples are wired end to end.

**Tech Stack:** Go 1.25, `net/http` `ServeMux`, SQLite via `database/sql` and sqlc, `github.com/go-json-experiment/json` (json v2, already in `go.mod`), the existing `eventlog`, `sessions`, `form`, `ui` packages.

**Spec:** `docs/superpowers/specs/2026-10-05-json-api-design.md` (after two rounds of Astra's review). Read it before any task. If this plan and the spec disagree, the spec wins; stop and report the disagreement.

## Global Constraints

- Gate: `make ci` from the repo root (it sets `GOFLAGS=-mod=mod`, `CGO_ENABLED=0`). Examples are separate modules: test them with `cd examples/<name> && GOFLAGS=-mod=mod go test ./...`.
- Run every `git` and `go` command with the bash sandbox **off** in this repo (phantom dotfiles and a read-only module cache inside it). Never `git add -A`; add named paths.
- Do not set `GOCACHE`, `GOMODCACHE` or `GOTMPDIR`. Scratch files go under `$TMPDIR`, never `/tmp`. Temp-dir Go builds need `-buildvcs=false`.
- Commits: imperative subject; the body says *why* (the failure prevented, the alternative rejected). End with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Commit identity in the worktree is `claude <claude~paul@keymail.dev>` (already set with `git config --worktree`).
- Comments say why, naming the failure prevented. A comment that restates code is noise.
- User-facing copy: short sentences, plain words, tell the reader what to do, **no em dashes**. Every new user-facing string is drafted in English only and listed in `docs/superpowers/plans/2026-10-05-json-api-copy.md` (Task 21 creates it) for Paul's copy review; translations are drafted only after that review. Do not ship translations in this plan.
- SKILL.md is byte-budgeted (`skillmd_test.go`). If it must grow, raise the ceiling in the test and say why; never cut a load-bearing fact.
- Token grammar: `<prefix>_<public id>_<secret>`; prefix `^[a-z][a-z0-9]{0,15}$`; public ID 12 base62 chars; secret 43 base62 chars; base62 alphabet `0-9A-Za-z`.
- Token defaults: expiry 90 days (choices 30, 90, 365 days, never); access "read and write" preselected.
- Agent headers: `Agent-Session`, `Agent-Harness`, each at most 200 bytes, no control characters, honoured only for agent tokens.
- API responses always carry `Cache-Control: no-store`. Default body cap 1 MiB.
- List defaults: `limit` 50, max 200. Order `created_at DESC, id DESC`.
- Freshness for minting tokens: `sessions.RequireFresh(10 * time.Minute)`.
- Error codes and statuses are exactly the spec's §6 table.

## Decisions already in the spec that tasks rely on

1. `rastrillo.Access` (`Read = 1`, `Write = 2`, zero invalid) and `rastrillo.Operation{ID, Resource string; Scoped bool; Access Access}` live in the root package to avoid an import cycle; `op.Descriptor` embeds `Operation` and adds `Exposed`.
2. `Actor.Credential != ""` means a token caller. Four caller kinds: token, signed-in, anonymous, app (spec §4 table).
3. `sessions.ActorFrom(r)` builds a page request's actor; the generated router uses it when the ctx factory left `Actor` zero.
4. `api.Config.Redact` is the redaction seam; `(*apitoken.Store).Redact` implements it.
5. `api.ErrUnauthorized` / `api.ErrUnavailable` are the sentinels a `Verifier` wraps.
6. `api.Config.Authorize` is required; the tree sets `rc.Authorize` from it. `op.DefaultPolicy` is exported for apps to name deliberately.
7. `op.Check` order: read-only credential on a Write op → Forbidden; scoped with no subject → Forbidden; `rc.Authorize` if set; else `DefaultPolicy`.

## Review Focus

1. **A token reaching an unscoped resource.** An app that exposes an unscoped resource but never sets `Authorize`: every token call must be 403, every page call must still work. Test in Task 5 and Task 19.
2. **A revoked token mid-session.** An agent holding a token that is revoked between two calls: the second call is 401 with the same body as an unknown token. Test in Task 9.
3. **Concurrent creates in a mergeable store.** Two goroutines creating at once must produce two records with their own owners. Test in Task 12.
4. **PATCH with an empty body `{}`.** Must be 200 with the unchanged row: no UPDATE, no event, `updated_at` unchanged. Test in Task 14.
5. **A token pasted into an error message.** A hand-written handler that returns `fmt.Errorf("bad token %s", tok)`: the log line shows only the public ID. Test in Task 8.

```go
package eventlog

import (
	"context"
	"errors"
	"fmt"
	"strconv"
	"strings"
)

// AppendNew starts a record: it takes the next id under streamPrefix
// (the largest numeric suffix of any stream there, plus one) and
// appends the record's first event to streamPrefix+id, in one BEGIN
// IMMEDIATE transaction on one pinned connection, as AppendChecked
// does.
//
// Reading the ids in one transaction and appending in another let two
// creates take the same id, and the fold then gave the later create's
// owner the earlier record. On one database that cannot happen now.
// Ids from two writers whose logs later merge are still the platform
// transport's to keep apart.
func (l *Log) AppendNew(ctx context.Context, streamPrefix, kind, actor string, payload any) (int64, Event, error) {
	if streamPrefix == "" || kind == "" {
		return 0, Event{}, errors.New("rastrillo/eventlog: stream prefix and kind must not be empty")
	}
	raw, err := marshalPayload(payload)
	if err != nil {
		return 0, Event{}, fmt.Errorf("rastrillo/eventlog: marshal payload: %w", err)
	}
	conn, err := l.db.Conn(ctx)
	if err != nil {
		return 0, Event{}, err
	}
	defer conn.Close()
	if _, err := conn.ExecContext(ctx, "BEGIN IMMEDIATE"); err != nil {
		return 0, Event{}, err
	}
	committed := false
	defer func() {
		if !committed {
			// WithoutCancel, as in AppendChecked: a cancelled request must
			// still release the write lock.
			conn.ExecContext(context.WithoutCancel(ctx), "ROLLBACK")
		}
	}()
	escaped := strings.NewReplacer(`\`, `\\`, `%`, `\%`, `_`, `\_`).Replace(streamPrefix)
	rows, err := conn.QueryContext(ctx, `SELECT DISTINCT stream FROM eventlog WHERE stream LIKE ? ESCAPE '\'`, escaped+"%")
	if err != nil {
		return 0, Event{}, err
	}
	var last int64
	for rows.Next() {
		var stream string
		if err := rows.Scan(&stream); err != nil {
			rows.Close()
			return 0, Event{}, err
		}
		n, err := strconv.ParseInt(strings.TrimPrefix(stream, streamPrefix), 10, 64)
		if err != nil {
			rows.Close()
			return 0, Event{}, fmt.Errorf("rastrillo/eventlog: stream %q has no numeric id after %q", stream, streamPrefix)
		}
		last = max(last, n)
	}
	if err := rows.Close(); err != nil {
		return 0, Event{}, err
	}
	if err := rows.Err(); err != nil {
		return 0, Event{}, err
	}
	id := last + 1
	ev, err := l.insert(ctx, conn, streamPrefix+strconv.FormatInt(id, 10), kind, actor, raw)
	if err != nil {
		return 0, Event{}, err
	}
	if _, err := conn.ExecContext(ctx, "COMMIT"); err != nil {
		return 0, Event{}, err
	}
	committed = true
	return id, ev, nil
}
```

```go
// encode is p as stored JSON with amounts merged in: a map, because an
// explicit null (a cleared field) is what a struct with omitempty cannot
// write.
func encode(p payload, amounts map[string]any) (json.RawMessage, error) {
	raw, err := json.Marshal(p)
	if err != nil {
		return nil, err
	}
	if len(amounts) == 0 {
		return raw, nil
	}
	var all map[string]json.RawMessage
	if err := json.Unmarshal(raw, &all); err != nil {
		return nil, err
	}
	for k, v := range amounts {
		if all[k], err = json.Marshal(v); err != nil {
			return nil, err
		}
	}
	return json.Marshal(all)
}
```

```go
// fold replays history and then the event about to be appended through
// the money rules. An event the fold refuses (an amount without its
// currency, a changed currency) would otherwise be written for good,
// and every later read of the stream, and every boot, would fail on it.
// Callers run it inside AppendChecked, on the history as it is under the
// write lock: a history read earlier let a racing writer clear the field
// and refill it in another currency in between.
func fold(rules replay.Rules, stream string, history []eventlog.Event, kind string, raw json.RawMessage) error {
	rec := map[string]replay.Field{}
	for i, ev := range append(history, eventlog.Event{Stream: stream, Kind: kind, Payload: raw}) {
		if err := rules.Apply(rec, i, ev); err != nil {
			return fmt.Errorf("%s: %w", stream, err)
		}
	}
	return nil
}
```

```go
	log, rules, err := q.open(ctx)
	if err != nil {
		return 0, err
	}
	p := payload{
		EventVersion: replay.Version,
		Title:        &arg.Title,
		CreatedAt:    &arg.Now,
	}
	amounts := map[string]any{}
	if arg.AmountMinor != nil || arg.AmountCurrency != nil {
		amounts["amount"], amounts["amount_currency"] = arg.AmountMinor, arg.AmountCurrency
	}
	raw, err := encode(p, amounts)
	if err != nil {
		return 0, err
	}
	// A new record has no history, so its first event is folded alone,
	// before it is written.
	if err := fold(rules, StreamPrefix+"new", nil, "created", raw); err != nil {
		return 0, err
	}
	id, _, err := log.AppendNew(ctx, StreamPrefix, "created", actor, raw)
	return id, err
}
```

- *`List`:* limit defaults to 50 and is capped at 200; `PageNumber > 0` is page mode (`Count<Plural>` with sqlc's bind convention, exactly `actionIndexGET`'s `countBinds` switch, then `List<Plural>` with `(PageNumber-1)*limit`); otherwise cursor mode reads `List<Plural>After` with `limit+1` rows. package op

```go
import (
	"bytes"
	"errors"
	"reflect"
	"strings"

	json "github.com/go-json-experiment/json"
	"github.com/go-json-experiment/json/jsontext"
)

// The messages DecodeInput refuses with. English, like every API
// message (spec section 6).
const (
	msgBody      = "Send one JSON object."
	msgUnknown   = "This field is not accepted."
	msgWrongType = "This value has the wrong type."
)

// acceptsNull marks the one field type a JSON null may fill.
type acceptsNull interface{ acceptsNull() }

func (Nullable[T]) acceptsNull() {}

var acceptsNullType = reflect.TypeFor[acceptsNull]()

// DecodeInput decodes one JSON object of arguments into dst, a pointer
// to a struct, with the API door's rules, for a caller that has no HTTP
// request: Descriptor.Invoke, and api.Decode once it has read the body.
// The value must be one object; an unknown member, a repeated name,
// trailing data, a wrong type and a null anywhere but a Nullable field
// are refused. A refusal is an Invalid keyed by the member's name, or by
// "body" when no one member is at fault.
func DecodeInput(data []byte, dst any) error {
	if t := bytes.TrimLeft(data, " \t\r\n"); len(t) == 0 || t[0] != '{' {
		return Invalid{Fields: map[string]string{"body": msgBody}}
	}
	var members map[string]jsontext.Value
	if err := json.Unmarshal(data, &members); err != nil {
		return Invalid{Fields: map[string]string{"body": msgBody}}
	}
	// v2 reads null into a plain field as its zero value, so {"id": null}
	// would quietly ask for row 0. Only a Nullable field may take it.
	for name, v := range members {
		if v.Kind() == 'n' && !nullable(reflect.TypeOf(dst), name) {
			return Invalid{Fields: map[string]string{name: errNull.Error()}}
		}
	}
	err := json.Unmarshal(data, dst, json.RejectUnknownMembers(true))
	if err == nil {
		return nil
	}
	var se *json.SemanticError
	if !errors.As(err, &se) || se.JSONPointer == "" {
		return Invalid{Fields: map[string]string{"body": msgBody}}
	}
	name, _, _ := strings.Cut(strings.TrimPrefix(string(se.JSONPointer), "/"), "/")
	switch {
	case errors.Is(err, json.ErrUnknownName):
		return Invalid{Fields: map[string]string{name: msgUnknown}}
	case errors.Is(err, errNull), errors.Is(err, errNoAmount):
		return Invalid{Fields: map[string]string{name: se.Err.Error()}}
	}
	return Invalid{Fields: map[string]string{name: msgWrongType}}
}

// nullable reports whether the member called name in struct type t (or
// a pointer to one) is a Nullable field, looking through inlined
// embedded structs as json does.
func nullable(t reflect.Type, name string) bool {
	for t.Kind() == reflect.Pointer {
		t = t.Elem()
	}
	if t.Kind() != reflect.Struct {
		return false
	}
	for i := 0; i < t.NumField(); i++ {
		f := t.Field(i)
		tag, opts, _ := strings.Cut(f.Tag.Get("json"), ",")
		if f.Anonymous && strings.Contains(","+opts+",", ",inline,") {
			if nullable(f.Type, name) {
				return true
			}
			continue
		}
		if tag == name {
			return f.Type.Implements(acceptsNullType)
		}
	}
	return false
}
```

```go
package op

import (
	"encoding/base64"
	"strconv"
	"strings"
	"time"
)

// EncodeCursor is the opaque next_after for a page that ends at the row
// (createdAt, id). It carries that row's own values rather than its id
// alone, so the next page starts in the right place in the list's
// (created_at, id) order, and still does after that row is deleted.
func EncodeCursor(createdAt string, id int64) string {
	return base64.RawURLEncoding.EncodeToString([]byte(createdAt + "|" + strconv.FormatInt(id, 10)))
}

// DecodeCursor reverses EncodeCursor. The empty cursor is the first
// page: ("", 0, true). Anything EncodeCursor could not have made is
// ok == false, so a hand-edited cursor is refused rather than read as
// some other place in the list.
func DecodeCursor(s string) (createdAt string, id int64, ok bool) {
	if s == "" {
		return "", 0, true
	}
	raw, err := base64.RawURLEncoding.DecodeString(s)
	if err != nil {
		return "", 0, false
	}
	at, idText, found := strings.Cut(string(raw), "|")
	if !found {
		return "", 0, false
	}
	if _, err := time.Parse(time.RFC3339, at); err != nil {
		return "", 0, false
	}
	id, err = strconv.ParseInt(idText, 10, 64)
	if err != nil || id < 1 {
		return "", 0, false
	}
	return at, id, true
}
```

```go
package op

import (
	"errors"

	json "github.com/go-json-experiment/json"
	"github.com/go-json-experiment/json/jsontext"

// errNoAmount is what a client sees for a money object with no amount.
var errNoAmount = errors.New("amount is required")

// UnmarshalJSONFrom reads {"amount": <integer>, "currency": "<code>"}.
// amount is required: decoded into a plain int64, {"currency": "USD"}
// would read as zero, and a price of nothing would be stored as if the
// client had sent it. currency may be left out; the operation fills it.
// Any other member is refused.
func (m *Money) UnmarshalJSONFrom(dec *jsontext.Decoder) error {
	var raw struct {
		Amount   *int64 `json:"amount"`
		Currency string `json:"currency"`
	}
	if err := json.UnmarshalDecode(dec, &raw, json.RejectUnknownMembers(true)); err != nil {
		return err
	}
	if raw.Amount == nil {
		return errNoAmount
	}
	*m = Money{Amount: *raw.Amount, Currency: raw.Currency}
	return nil
}

var _ json.UnmarshalerFrom = (*Money)(nil)
```

```go
// number it also counts them, for the page door's numbered links. After
// a cursor it reads one row more than it returns, so it knows whether
// there is a next page without counting.
func List(ctx context.Context, rc *rastrillo.Ctx, in ListInput) (Page, error) {
	if err := op.Check(ctx, rc, ListOp); err != nil {
		return Page{}, err
	}
	limit := in.Limit
	if limit < 1 {
		limit = 50
	}
	if limit > 200 {
		limit = 200
	}
	search := strings.TrimSpace(in.Search)
	store := bookmarksstore.New(rc.DB)
	if in.PageNumber > 0 {
		total, err := store.CountBookmarks(ctx, bookmarksstore.CountBookmarksParams{
			Owner:  rc.Actor.Subject,
			Search: search,
		})
		if err != nil {
			return Page{}, err
		}
		rows, err := store.ListBookmarks(ctx, bookmarksstore.ListBookmarksParams{
			Owner:      rc.Actor.Subject,
			Search:     search,
			PageOffset: int64((in.PageNumber - 1) * limit),
			PageLimit:  int64(limit),
		})
		if err != nil {
			return Page{}, err
		}
		return Page{Items: items(rows), Total: total}, nil
	}
	afterAt, afterID, ok := op.DecodeCursor(in.After)
	if !ok {
		return Page{}, op.Invalid{Fields: map[string]string{"after": "Use the next_after value from the previous page."}}
	}
	rows, err := store.ListBookmarksAfter(ctx, bookmarksstore.ListBookmarksAfterParams{
		Owner:          rc.Actor.Subject,
		Search:         search,
		AfterCreatedAt: afterAt,
		AfterID:        afterID,
		PageLimit:      int64(limit + 1),
	})
	if err != nil {
		return Page{}, err
	}
	var next string
	if len(rows) > limit {
		rows = rows[:limit]
		next = op.EncodeCursor(rows[limit-1].CreatedAt, rows[limit-1].ID)
	}
	return Page{Items: items(rows), NextAfter: next}, nil
```

```go
// update reads the row, merges what was sent and writes the whole row
// back, in one transaction. That is atomic because rc.DB is the writer
// pool, which has one connection: no other write can run between the
// read and the write. Nothing here may use rc.DB while tx is open, or it
// waits for the connection tx holds.
func update(ctx context.Context, rc *rastrillo.Ctx, id int64, in UpdateInput) error {
	tx, err := rc.DB.BeginTx(ctx, nil)
	if err != nil {
		return err
	}
	defer tx.Rollback()
	store := bookmarksstore.New(tx)
	row, err := store.GetBookmark(ctx, bookmarksstore.GetBookmarkParams{ID: id, Owner: rc.Actor.Subject})
	if errors.Is(err, sql.ErrNoRows) {
		return op.NotFound{}
	}
	if err != nil {
		return err
	}
	arg := bookmarksstore.UpdateBookmarkParams{
		Title: row.Title,
		Link:  row.Link,
		Notes: row.Notes,
		Now:   time.Now().UTC().Format(time.RFC3339),
		ID:    id,
		Owner: rc.Actor.Subject,
	}
	if in.Title.Set {
		arg.Title = strings.TrimSpace(in.Title.Value)
	}
	if in.Link.Set {
		arg.Link = strings.TrimSpace(in.Link.Value)
	}
	if in.Notes.Set {
		arg.Notes = in.Notes.Value
	}
	n, err := store.UpdateBookmark(ctx, arg)
	if err != nil {
		return err
	}
	if n == 0 {
		return op.NotFound{}
	}
```

```go
// when it has one, else the one sent, else USD, the resource's default.

// change-currency operation's job), so a different one is op.Conflict.
func settle(name string, m op.Money, held *string) (*int64, *string, error) {
	code := "USD"
	if held != nil {
		code = *held
```

```go
	}

// page sends one request through the signed-in client without following
// redirects, so a 303 is seen as the page door's success. Sec-Fetch-Site
// is what a browser sends with its own form, which csrf.Protect
// accepts.
func page(t *testing.T, c *http.Client, method, p string, f url.Values) string {
	t.Helper()
	cc := *c
	cc.CheckRedirect = func(*http.Request, []*http.Request) error { return http.ErrUseLastResponse }
	var body io.Reader
	if f != nil {
		body = strings.NewReader(f.Encode())
	}
	req, err := http.NewRequest(method, base+p, body)
	if err != nil {
		t.Fatal(err)
	}
	if f != nil {
		req.Header.Set("Content-Type", "application/x-www-form-urlencoded")
	}
	req.Header.Set("Sec-Fetch-Site", "same-origin")
	res, err := cc.Do(req)
	if err != nil {
		t.Fatal(err)
	}
	defer res.Body.Close()
	switch res.StatusCode {
	case http.StatusOK:
		return "ok"
	case http.StatusSeeOther:
		return "ok " + res.Header.Get("Location")
	case http.StatusBadRequest:
		return "invalid"
	case http.StatusNotFound:
		return "not_found"
	}
	b, _ := io.ReadAll(res.Body)
	t.Fatalf("%s %s: the page door answered %d: %s", method, p, res.StatusCode, b)
	return ""
}

// call sends one API request with token and answers its kind and its
// decoded body.
func call(t *testing.T, h http.Handler, token, method, p string, body any) (string, map[string]any) {
	t.Helper()
	var r io.Reader
	if body != nil {
		b, err := json.Marshal(body)
		if err != nil {
			t.Fatal(err)
		}
		r = bytes.NewReader(b)
	}
	req := httptest.NewRequest(method, base+p, r)
	req.Header.Set("Authorization", "Bearer "+token)
	if body != nil {
		req.Header.Set("Content-Type", "application/json")
	}
	rec := httptest.NewRecorder()
	h.ServeHTTP(rec, req)
	var out map[string]any
	if rec.Body.Len() > 0 {
		if err := json.Unmarshal(rec.Body.Bytes(), &out); err != nil {
			t.Fatalf("%s %s: %v: %s", method, p, err, rec.Body)
		}
	}
	switch rec.Code {
	case http.StatusOK, http.StatusCreated, http.StatusNoContent:
		return "ok", out
	case http.StatusUnprocessableEntity:
		return "invalid", out
	case http.StatusNotFound:
		return "not_found", out
	}
	t.Fatalf("%s %s: the API door answered %d: %s", method, p, rec.Code, rec.Body)
	return "", nil
}
```
