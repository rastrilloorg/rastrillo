{{/* pagination — a numbered page strip of ordinary links, so paging works with JavaScript disabled. The current page carries aria-current="page" as well as a filled chip and a heavier weight: three signals, never colour alone. A disabled item is a plain span with a class, not aria-disabled: that attribute belongs on elements with an interactive role, and a bare span has none. The class is what tokens.css styles (dashed border, faint text) — friction log F10 in examples/blog is what happens when the two drift apart. Keys: Items slice, optional — one entry per control. Each has: Label string — the visible text ("1", "Next") Href string — where it goes Current bool — this is the page being viewed Disabled bool — present but not actionable Gap bool — the "…" between page ranges Exactly one of Href / Current / Disabled / Gap is meaningful per item. Label string, optional — the
's accessible name, default resolved through T ("rastrillo.ui.pagination" — "Pagination" in the framework base catalog; see Funcs/FuncsWith). An app passing its own Label always wins over T. */}} {{define "pagination"}}
