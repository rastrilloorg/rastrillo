{{/* pagination — a numbered page strip of ordinary links, so paging works with JavaScript disabled. The current page carries aria-current="page" as well as a filled chip and a heavier weight: three signals, never colour alone. A disabled item is a plain span carrying rst-pagination-disabled, never aria-disabled: that attribute belongs on elements with an interactive role, and a bare span has none. The attribute is what tokens.css styles (dashed border, faint text) — friction log F10 in examples/blog is what happens when the two drift apart. Keys: Items slice, optional — one entry per control. Each has: Label string — the visible text ("1", "Next") Href string — where it goes Current bool — this is the page being viewed Disabled bool — present but not actionable Gap bool — the "…" between page ranges Rel string, optional — "prev" on the Previous item, "next" on the Next item. Read reflectively (opt), so a struct without the field still renders. Exactly one of Href / Current / Disabled / Gap is meaningful per item. Label string, optional — the
's accessible name, default resolved through T ("rastrillo.ui.pagination" — "Pagination" in the framework base catalog; see Funcs/FuncsWith). An app passing its own Label always wins over T. On a phone the strip is one line: the items with a Rel are drawn as chevrons, their words kept in rst-pagination-word for a screen reader; only the first, the current and the last page show, with one ellipsis per skipped run. paginationItems (funcs.go) decides which items those are. A strip with no Rel renders on a phone as it always has: nothing else can tell a step from a page. rst-pagination-wide marks what only a wide strip shows, and rst-pagination-gap="narrow" an ellipsis only a phone shows. The chevron is chevron-down turned a quarter, because every icon set an app can scaffold has that one. */}} {{define "pagination"}}
