{{/* field-money: one labelled money input in one currency, with optional hint and error lines wired as field-text wires them. Being inside the label, it is also part of the input's accessible name. Three hidden inputs travel with the text (spec §5): .locale the locale the text is written in. It is always rendered, empty when Seed is. inputmode="decimal" brings up a number keyboard with a decimal mark. It is type="text", not type="number": a number input refuses a currency sign, grouping and the other locale's decimal mark, all of which the server reads. The wrapper repeats field-text's rather than composing it, for the reason field-text's own comment gives.
